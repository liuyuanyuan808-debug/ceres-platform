# Ceres 3期需求原型

Ceres 吸奶器管理平台3期交互原型。目标由 Ceres 统一维护设备的新旧韵律及配置版本，AIoT 接收并透传韵律，负责 App 端展示设计与配置。当前 AIoT 维护旧韵律并支持新韵律传入；本期在 Ceres 补齐旧韵律管理能力。

原型默认进入新增的旧韵律页面，覆盖以下功能：

- 动力源方案管理（3期新增版本管理：草稿、停用升版、历史快照与对比）
- 模式单元库
- 模式库
- 韵律管理
  - 新韵律（现有韵律库，独立页面）
  - 旧韵律（3期新增，独立页面；统一命名下逐型号管理，支持原参数后续补录、完整性红点和独立发布状态）
- 模式单元频率策略与可选 Speed 分档

在本目录运行 `python3 -m http.server 8173`，打开 `http://localhost:8173/` 即可预览。

变更范围及演示约定见「需求变更说明.md」。发布使用独立的 `/v3/` 路径。

“吸乳方案配置”下的“韵律管理”可展开、收起，下设“新韵律”和“旧韵律（3期新增）”两个独立页面。

按型号和实际固件分发的规则见三期需求文档：每个型号固定一种韵律协议，旧协议型号仅用旧韵律，新协议型号仅用新韵律；固件仅校验该协议内兼容范围，本期不支持跨协议固件升级。标签仅用于匹配池内内容投放。本原型不包含独立投放管理或实际 OTA 页面。

2026-11-12：新旧韵律统一为“韵律命名主行 → 型号配置明细 → 完整参数”。主行明确维护归属关系，不再按名称与总时长自动合并；型号分别绑定动力源方案版本、执行参数、发布状态和参数完整性。

旧韵律可保留外层命名与编排，后续补录原执行参数。红点只表示已提交的完整参数仍有缺失，浏览或保存未完成草稿不会清除；补录不改变原系统已发布状态。完整校验并确认原值后提交补录，仅清除对应型号红点。已发布内容调整时另建独立 2.0 条目。

2026-11-13：去除绿色变更框及重复说明，列表、型号展开和详情沿用模式库、模式单元的标准后台样式。型号档位参数档案及导入界面去除黄色变更底色。新旧韵律仍保持两个独立导航入口，列表和详情布局一致；新韵律展示模式组合及按型号解析得到的完整参数。交互数据保存在独立的演示存储中，不连接实际 AIoT 或设备。
