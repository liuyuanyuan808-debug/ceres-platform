本地预览：http://127.0.0.1:8137/

## 当前入口：单手机评审工作台

本地预览：http://127.0.0.1:8137/?v=20261119-11

`index.html` 是固定在当前窗口的评审工作台：左侧切换功能，中间始终只有一个手机 Demo，右侧跟随当前功能显示简短定义。没有上下排列的原型列表，也没有横向手机画廊；切换功能和场景均通过导航与 Tab 完成。

- 左侧四个入口：异常识别与故障态、温馨提示与受限操作、多设备与多异常、问题提交。
- 每个入口的场景以 Tab 切换。异常识别直接进入异常演示，不再提供“正常状态”；其他场景如温馨提示 / Sync、多条提示 / 逐项恢复继续以 Tab 切换。
- 异常演示选择 E05 / E53 后，点击“触发异常”在当前手机里显示对应弹窗或提醒；确认后的故障标记、温馨提示、受限操作保持可交互。
- 多设备场景点击“触发双侧异常”，演示左右设备各自的 E05 / E53、阻断队列与独立提醒；“逐项恢复”可按侧别及异常分别操作。
- 问题提交在同一手机里通过四个功能 Tab 切换，并在各功能下选择正常、无日志、断网、成功、失败、中断、跨日等场景。
- 外部事件按钮只演示当前场景。各场景的数据独立保存，切换后再返回，保留已确认的异常、恢复进度、调档与提交任务。重置只影响当前场景。
- App 逻辑画布仍为 390 × 848；工作台根据窗口空间等比显示整个手机，不拉伸画面。App 内原有页面滚动保留，不依靠工作台翻页寻找其他原型。
- 左侧和右侧保留较大的字号。右侧可折叠；窄屏默认收起定义，可按需展开。
- 功能、场景、事件按钮、文案及六类定义集中在 `review-data.js`；右侧依据文档修订 900 的既有内容，业务规则没有随本次布局调整而变更。
- E53 仍为指定的跨型号组件样例，不代表 M5 Ultra 支持；没有新增真实加热控件。
- 原 App 入口保留在 `app.html`。提交、网络、云端确认、跨日仍为本地模拟，未连接真实服务。

## 文档增补：7.2.1 异常样例

依据[吸奶器错误码治理｜新版控制页](https://momcozy-in.feishu.cn/wiki/KSrbwkhsTiIHHRkz2pjc3Va3nqb)。用户已确认将原提及的 E105 改为文档中的 E05。

- 画布外右侧保留两个圆形按钮：E53 事件提醒、E05 阻断弹窗；窄屏时演示面板移到画布上方。
- **E53，右侧**：提示“未检测到法兰，暂不可加热，请重新安装并卡紧”；沿用紧凑圆角提示条样式，可收起、展开和关闭。只保留该侧加热限制，吸奶和调档仍可操作。关闭后本轮重复上报不重新提醒，每次上报仍记录日志。
- **E05，左侧**：提示“电池温度过高，设备暂停使用”；沿用背景模糊、灰色遮罩和圆角弹窗样式，按钮改为“我知道了”。点击仅确认提示，左侧仍暂停且不可调档；右侧继续可用。蒙层与 Escape 不关闭。
- Both 只调整可操作的一侧；双侧开始也只启动可用侧。设备确认恢复后解除对应限制，不自动恢复已暂停侧的吸奶。
- E53 提醒与 E05 弹窗分别保存；确认、关闭、切页和提交日志互不解除异常。点击“设备确认恢复”模拟设备明确解除现有样例，之后可重新演示新一轮异常。
- 原型页面只显示状态、建议和侧别；原始错误码仅保存在本地演示日志和画布外的演示按钮中。
- 当前录屏设备为 M5 Ultra，文档的 M5 Ultra 支持列表未包含 E53；E53 仅作为用户指定的跨型号组件样例，不能据此认定 M5 Ultra 支持该错误上报。画布外已标注此边界，没有新增未经展示的加热控件。

## 文档增补：7.2.2 错误码日志与问题提交

Manage Devices 的 General Settings 下方、Delete 上方新增“帮助与支持”，其中“问题提交”副文案为“提交设备问题信息，供客服排查”。点击原入口直接校验并提交，无二次页面或确认。

按 2026-11-18 最新文档，右侧精简为以下四个功能按钮。点击后进入对应状态，仅显示该项相关的“演示情境”选项；真实入口始终位于原设置页。任务执行期间不能切换情境或发起重复任务。

| 右侧按钮 | 可查看的效果 |
| --- | --- |
| 1. 入口与提交校验 | 默认定位到设置页入口，等待点击；可切换“无待提交日志”“网络不可用”“蓝牙断开”，查看校验反馈或点击入口提交。 |
| 2. 提交中与防重复 | 直接显示“提交中…”和转圈并禁用入口；期间自动追加一条演示日志，本次成功后该条仍待提交。 |
| 3. 提交结果与手动重试 | 默认演示成功确认；可切换失败场景，保留日志并恢复入口，等待用户再次点击“问题提交”手动重试。 |
| 4. 页面返回与中断恢复 | 默认演示较长任务，可返回控制页、重新进入设置页或刷新查看实际状态；可切换中断场景，保留日志并恢复入口供手动重试。 |

“重置演示”为辅助操作，清除本原型的异常和问题提交演示状态，停止本次演示吸奶，不清除既有吸奶记录。

- 每次模拟收到异常发生或解除信息均生成本地日志，包括重复上报；保留 timestamp、event_id、content 中的明文错误码与发生／解除状态、原始文案、设备与侧别。字段值为原型演示数据，不代表最终协议或埋点定义。
- 先校验待提交日志，再校验网络及账号归属；提交范围固定为 UTC 当天 0 点到点击时刻的待提交日志。任务中新增内容不混入当前任务，成功仅清理该任务已确认的记录。
- 失败、超时、中断均保留未确认日志并等待手动重试；模拟云端按日志标识去重。切页、刷新与再次进入保留任务实际状态，不重新发起任务。
- UTC 0 点清理上一日实时待提交缓存；页面恢复可见、追加日志和点击提交时也会复核日期。清缓存和提交结果都不改变设备异常。
- 提交时长通常约 6 秒，“提交中与防重复”约 9 秒，“页面返回与重进”约 14 秒，为评审演示值，不是产品超时规则。

**原型边界**：任务结果、蓝牙、网络与云端日志均在本地模拟，没有连接真实设备、上传接口或客服查询接口。账号／归属异常的既有 App 反馈、接口、成功判定和真实超时参数，文档未给出完整定义，继续待确认；不编造该状态的产品文案。

## 操作

拖动左右档位条调整单侧；拖动中间 Both 手柄调整双侧。点击模式、设置和设备卡片切换页面。开始吸乳后持续按住 Hold To End 约 2 秒，打开记录面板。拖动粉色奶量控件调整数值，展开 Duration 调整时长，Save 后显示加载与成功状态。

双侧/单侧档位及奶量也支持方向键；单侧档位和奶量支持 Home / End。录屏中的底部面板可用关闭按钮退出；异常阻断弹窗须点“我知道了”确认。录入内容在 Save 成功后保存在当前浏览器的本地存储中。

## 仍有差异与证据边界

- 没有原始字体文件；正文使用系统字体，记录页衬线标题和奶量字体为近似还原。返回、设置、刻度等部分图标使用 SVG 近似描摹。
- 从视频截取的设备图及兔子动画存在压缩与抠图边缘差异；兔子使用视频中的 21 帧局部动画，未生成新插画。
- 长按阈值采用约 2 秒，保存加载约 7.8 秒，成功状态约 1.8 秒；这些为视频观测近似值，不代表真实产品规则。
- 第一次记录面板的退出触发无法明确判定。原型提供 × 关闭，关闭不会自动保存；保存遵循第二次明确出现的“加载 → Logged → 返回”流程。
- 视频未展示暂停/恢复、Sync 开关、Swap、改名、复制、删除、20 s / 30 s / Custom、日期选择和三个 Confirm 的后续结果。这些入口保留外观，不接入推测流程。
- Both 的完整联动规则未知；当前按拖动距离同时增减两侧档位，并限制在视频显示的 1–9。
- 时长滚轮覆盖视频可见的分钟 00–02、秒 00–09；若真实吸乳计时超出此范围，会保留当次计时并扩展到该当前值。未据此推断完整产品范围。
