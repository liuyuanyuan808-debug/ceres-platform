# Ceres 2.1 需求变更原型

Ceres 吸奶器管理平台交互原型，默认进入新增的旧韵律页面，覆盖以下功能：

- 动力源方案管理（2.1新增版本管理：草稿、停用升版、历史快照与对比）
- 模式单元库
- 模式库
- 新韵律（现有韵律库）
- 旧韵律（按型号创建，沿用 AIoT 阶段配置，采用 Ceres 草稿 / 发布 / 停用与版本规则）
- 模式单元频率策略与可选 Speed 分档

在本目录运行 `python3 -m http.server 8171`，打开 `http://localhost:8171/` 即可预览。

变更范围及演示约定见「需求变更说明.md」。发布使用独立的 `/v2.1/` 路径。
